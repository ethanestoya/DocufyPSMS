What changes, and why

  1. One committing action per row. "View" becomes a quiet text action, "Release" is the single blue button — you can no longer mis-click the passive control.
  2. Urgency is visible. Each waiting row gets a left rail and an "N days overdue" line, so a 5-day-old order no longer looks like a fresh one.
  3. Red appears once. The status badge keeps the red; the amount goes neutral black with a small caption. The deadline text turns red only on an actual offence.
  4. Deadline is scanned, not read twice. Date on the first line, the repeated time muted beneath it.
  5. The note line keeps its height whether a filter is on or off, so the table never jumps when you switch chips.
  6. Nothing about the counts changes. Ready 3 + Overdue 6 + Picked up 1 + Picked up late 1 = All 11, and Unclaimed stays 6 — the same records Unclaimed Orders counts.
