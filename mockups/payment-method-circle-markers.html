Recommended card, circle-only selection markers

The card treatment stays exactly as approved — #EAF2FF fill, 2px #1668D9 border, solid icon chip, lift shadow — and only the round marker changes. The check is gone on purpose: in Docufy a tick already means completed / verified (order status, payment verified), so it fights the meaning here. A circle says “this option is on” and matches how radios behave everywhere else in the app.

Implementation note. Every option is the app’s existing RadioGroupItem restyled — no custom check glyph and no extra markup, so arrow-key navigation, label association and the selected value keep working untouched. 22px is the target a thumb actually hits on a phone and lines up with the 40px icon chip. Unselected cards keep the hollow grey circle, so the affordance never disappears.
