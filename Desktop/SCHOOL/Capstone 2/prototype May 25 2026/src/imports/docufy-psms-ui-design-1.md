Design a clean, modern, and professional web-based system UI for DocuFy PSMS (Printing Shop Management System) intended for use in a university printing shop. The prototype should feature role-based login supporting three roles: Customer, Staff/Employee, and Admin. The interface should follow a DocuFy-inspired modern dashboard style, using DocuFy Blue (#2F6FD6) as the primary color, combined with white backgrounds and very light blue or gray panels. UI components such as cards should have rounded corners, soft shadows, and clean spacing, while typography should use Inter or Poppins for a polished look. Buttons should include blue primary buttons and gray secondary buttons, and the system should use simple line icons to maintain a minimal and uncluttered appearance with clear section headers and consistent spacing. The prototype should include desktop frames (1440px) and a mobile version for key customer pages such as login and order tracking.

The authentication flow begins with a public landing page featuring the DocuFy logo, the tagline “Your Printing Companion,” and primary buttons for Log In, Create Account (Customer), and Track Order, along with a small Services & Pricing section and a shop hours and location card within a clean hero layout. The Log In page should have a centered login card with the DocuFy logo, input fields for Email/Username and Password, a Log In button, and a Create Account link for customers, along with a note stating that staff accounts are created by the administrator. After login, users should be automatically redirected based on their role: Admin to the Admin Dashboard, Staff to the Staff Queue Board, and Customers to the Customer Dashboard, with a small explanation box indicating that the system performs automatic role-based redirects. A Customer Sign-Up page titled “Create Customer Account” should include fields for Full Name, Email, Contact Number, Password, and Confirm Password, along with a checkbox agreeing to the terms and file retention policy, buttons for Create Account and Back to Login, and a note explaining that staff accounts cannot sign up and must be created by an administrator.

After logging in, customers access a Customer Portal with a left sidebar and main content layout, where the sidebar includes Dashboard, New Print Request, My Orders, Track Order, Job Board, Profile, and Logout, while the top bar shows the user name and notifications icon. The Customer Dashboard should display a welcome header, three quick-action cards (New Print Request, Track My Order, Job Board), and a Recent Orders table showing Order ID, Status, Total, and Date. The New Print Request page should use a step-by-step wizard including document upload with page detection, print options such as paper size (Short, A4, Long), copies, and color mode (Black & White or Colored), a section for additional printing notes, and a summary page displaying page count, size, copies, print mode, and total amount, highlighting the rule that orders totaling ₱20 or more require payment verification, followed by a Place Order button. If the order meets that condition, the system displays a Payment Verification page showing admin payment details, instructions to pay a partial amount, an input field for the reference number, optional proof of payment upload, and a Submit Reference button, with a status label “Waiting for Admin Verification.” The Order Tracking page should present a five-stage progress timeline (Received → In Queue → Printing → Completed → Released), an order summary card, a payment status badge (Not Required, Pending, Verified, or Rejected), and pickup schedule information. The Job Board page should list available services in card format with service title, description, and an Apply button, which leads to an application form requesting Name, Contact, Service Applying For, Skills or Message, and an optional portfolio link.

The Staff Portal should feature a sidebar with Queue Board, Walk-in Transactions, and Logout. The main Queue Board page should display a Kanban-style board with columns for Received, In Queue, Printing, Completed, and Released, where each order card shows Order ID, customer name, page count, print type, and an Open Details button. Staff should also have access to a Walk-in Transactions page containing a quick form for photocopy or supply purchases, automatic total calculation, and a Save Transaction button.

The Admin Portal should include a sidebar menu for Dashboard, Payment Verification, Orders, Inventory, Employees, Reports, Accounts (Create Staff), Job Board Management, and Logout. The Admin Dashboard should present KPI cards showing Orders Today, Pending Verifications, Sales Today, and Low Stock Alerts, along with simple charts such as sales trends and order volume. The Payment Verification page should list submitted payment references with Approve and Reject buttons, while the Accounts page should include a Create Staff Account form with fields for name, email, temporary password, and role set to staff. The Inventory page should show a stock list with low-stock indicators, and the Reports page should allow date range filtering and report downloads. Finally, the prototype should include interactive navigation links connecting the main flows, such as Landing to Login, Landing to Sign Up, Login to each role dashboard, Customer New Print Request to Payment Verification when the total reaches ₱20 or more, Payment Verification to Order Tracking, and Job Board to the Apply Form, ensuring that the entire interface remains consistent with the DocuFy brand style across all portals.
