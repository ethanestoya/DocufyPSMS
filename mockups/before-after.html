Also fixed in code this batch
The four error reports, plus a check on the validation item.
Error messages
Names the real cause. Schema drift, oversized or unsupported uploads no longer read as “something went wrong”.
Inventory
No false failure. Archiving reports success and flags only the server copy as behind.
Profile & photo
Says which half failed — details or picture — and why, and cleans up a stranded upload.
Attendance
Retries once, then one notice. It no longer reappears on the Payment Verification page.
Contact number
Digits only, exactly 11. The job application form already enforces it; verified, no change needed.
Data-breach alert: a Google Password Manager notice about a reused/leaked password — not an application defect. No password field exists outside login, sign-up and reset, all correctly marked for the browser.
